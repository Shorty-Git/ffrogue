# BISHAMON WebGL evaluation inquiry draft

Draft only. Not sent. Vendor contact route:
[MATCHLOCK contact](https://www.matchlock.co.jp/contact/).

Subject: BISHAMON WebGL SDK evaluation and legacy BMB compatibility

Hello MATCHLOCK team,

I am evaluating BISHAMON browser playback for a private, non-commercial prototype.
The CEDEC2018 report by ICS describes an Emscripten-built BISHAMON WebGL SDK.
Could you confirm whether an evaluation version is currently available and which
evaluation/use options apply to an individual developer?

The existing legacy resources use IBMB/BMB data with version bytes 01 01 03 01,
along with M3R models and texture/material resources. Can your WebGL SDK load
that data directly, or would matching BMSLN sources and a particular converter
or shader package be required?

For evaluation, I would need documented resource loading, manual time stepping,
reset/seed controls if supported, and external camera matrices. Can the SDK share
a WebGL context with another renderer, or draw to a transparent separate canvas?

Please also confirm whether a WebGL build is a separate SDK from the Personal
DirectX11 SDK listed in your store, and how I can obtain the relevant evaluation
package and compatibility documentation.

Thank you.
